# 지원 지역 선정 기록

## 출처

- 행정안전부 주민등록 인구통계 「행정동별 연령별 인구현황」 (https://jumin.mois.go.kr/ageStatMonth.do)
- 기준 시점: **2016년 12월 말**, 연령 구간: **15~19세**, 구분: **거주자**
- 조회 가능 기간: 2008년 1월 ~ 2026년 (사이트 조회 화면에서 확인)
- 자료 수집: 사용자가 직접 엑셀로 내려받아 정렬함 (캡처 이미지 보관 → 보고서 첨부)

## 선정 기준

- 단위: **자치구** (계획서의 행정동에서 변경, `plan_changes.md` 참고)
- 서울특별시: 15~19세 거주자 상위 5개 구 (처음 10개 구로 선정 → 조사 시간 부족으로 상위 5개 구로 축소)
- 인천광역시: 15~19세 거주자 **20,000명 이상**인 구 (10개 군·구 중 6곳)
