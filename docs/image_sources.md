# 이미지 출처와 수집 방법

| 이미지 | 위치 | 수집 방법 | 출처 표시 |
|---|---|---|---|
| 영화·TV방송 포스터 | `static/images/trends/<연도>/*-movie-*`, `*-tv-*` | `tools/fetch_tmdb_posters.py` (TMDB API) | 카드 "이미지: TMDB" + 푸터 TMDB 고지문 |
| 게임 표지 | `static/images/trends/<연도>/*-app-*` | `tools/fetch_igdb_covers.py` (IGDB API) | 카드 "이미지: IGDB" + 푸터 |
| 앨범 커버 | `static/images/trends/<연도>/*-song-*` | `tools/fetch_itunes_artwork.py` (iTunes Search API, 키 불필요) | 카드 "이미지: Apple Music" + 푸터 |
| 간식 사진 | `static/images/trends/<연도>/*-snack-*` (가로 600px로 줄인 사본) | 네이버 이미지 검색 (아래) | 카드 "이미지: 네이버 블로그 (CCL)" |
| 놀이 사진 | `static/images/trends/play/` (여러 해에 같은 사진) | 사용자 직접 수집 | (출처 미기록 → 보완 필요) |
| 지역 추억 사진 | `static/images/memories/<구>/<추억id>.jpg` (가로 900px로 줄인 사본) | 사용자 직접 수집, 네이버 이미지 검색 (간식과 같은 방법) | (출처 미기록 → 보완 필요) |
| 부평역·문화의 거리 연도별 사진 | `static/images/memories/bupyeong/bupyeong-5·6-<연도>.jpg` (가로 1200px로 줄인 사본) | 지도 서비스 로드뷰의 과거 사진을 직접 캡처 | (서비스명 미기록 → 보완 필요) |

## 폴더·파일 이름 규칙 (2026-11-23 정리)
- **지역 추억은 구별 폴더**: `memories/<구>/<추억id>.jpg`, 연도별 사진은 `memories/<구>/<추억id>-<연도>.jpg` (구 이름은 추억 id 앞부분: seo, bupyeong, gangnam …)
- **전국 유행은 연도별 폴더**: `trends/<연도>/<유행id>.jpg`. 여러 해에 같은 사진을 쓰는 놀이 사진만 `trends/play/play-<이름>.jpeg`
- 이미지 수집 도구는 `tools/common.py`의 `trend_image_path()`로 같은 규칙(연도 폴더)에 저장
- 화면용으로 줄인 사본만 남기고, 원본 사진(로드뷰 캡처 PNG, 노원구 사진 등)은 삭제함. `DEMO_images/` 폴더는 비어서 없앰
- 노원 크리스마스 축제 사진(`memories/nowon/nowon-2.jpg`)은 **연합뉴스 워터마크**가 있는 보도사진 → 시연용으로만 사용, 배포 시 교체 필요
- 노원탈축제는 기본 사진 1장 + 2014·2016·2017·2019·2022년 축제 사진 (그 해에만 연도별 사진 표시)
- 쓰지 않는 사진, 지원 기간 밖(2023년) 캡처는 삭제함
- 계산 나무놀이터(`gyeyang-7`)는 사진 3장을 함께 표시 (`gyeyang-7-1~3.jpg`, 가로 900px로 줄이고 원본 삭제)
- 계양산(`gyeyang-6`)은 2015년·2016년 사진이 같은 파일이어서 하나만 남기고, 산은 해마다 모습이 거의 같으므로 연도별 사진이 아닌 **기본 사진**으로 옮김 (2013~2022 모두 표시, "○○년 모습" 배지 없음)
- 송도맥주축제(`yeonsu-3`)는 2014년 사진을 기본 사진으로 지정 → 2016년에만 "2016년 모습", 나머지 해는 기본 사진 (축제는 이전 해 사진을 이어 쓰지 않음)

## 간식 사진 검색 방법 (네이버 이미지 검색 옵션)
- **기간:** 해당 연도로 지정 (예: 2018.01.23 ~ 2018.12.23) → 그 시기에 올라온 사진을 찾아 당시 모습에 가깝게
- **출처:** 전체 (네이버 블로그, 네이버 카페)
- **CCL:** "CCL 전체" → 저작자가 이용 조건(CCL)을 표시한 사진만 검색
- 크기·유형·색상: 전체

## 화면용으로 줄인 이유
- 원본 캡처 PNG 17장이 43MB(장당 2~4MB)라 연도 버튼을 누를 때마다 느렸음
- Windows 기본 이미지 처리(.NET System.Drawing)로 가로 1200px(로드뷰)·600px(간식) JPG로 변환 → 장당 10~200KB
- 원본 PNG는 정리하면서 삭제함 (화면용 사본만 사용)

## 한계 (보고서에 기록)
- "CCL 전체"에는 비영리(NC)·변경금지(ND) 조건이 섞여 있음. CCL은 대부분 **저작자 표시(BY)**가 조건인데,
  사진마다 원 게시글 주소·작성자를 기록하지 않아 개별 저작자 표시를 하지 못함. 크기 축소가 ND 조건에 해당하는지도 불확실.
- 포스터·앨범 커버·게임 표지의 저작권은 제작사에 있음. API 이용 조건과 별개이므로 **웹 배포는 하지 않고**
  비공개 시연용으로만 사용.
- 로드뷰 캡처는 지도 서비스의 저작물이므로 같은 이유로 배포하지 않음.
