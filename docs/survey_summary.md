# 사전 사용자 설문 결과 요약

- 원자료: `추억 서비스 사전 설문.csv` (Google 설문 응답)
- 응답 기간: 2026-10-25 ~ 2026-11-05
- 응답자: **11명**, 전원 20~23세 (계획서 목표: 20대 5명 이상 → 충족)
- 16세 무렵 거주 지역: 인천 9명, 서울 2명

## 주요 결과
| 질문 | 결과 |
|---|---|
| 자료를 찾지 못해 그만둔 경험 | 있다 7명 / 없다 4명 |
| 학창 시절 이야기를 더 나누고 싶은 경험 | 있다 9명 / 없다 2명 |
| "추억을 사진으로 확인해 보고 싶었다" 선택 | 8명 |
| 추억을 떠올릴 때 본 자료 (복수 응답) | 개인 사진·앨범 10, SNS·커뮤니티 6, 아무것도 안 봄 4, 지도·로드뷰 1 |
| 16살 하면 떠오르는 것 (복수 응답) | 대중문화 6, 놀이·게임 5, 동네 가게·장소 4, 패션 1, 학교 1 |
| 추억을 나눌 때 가장 중요한 점 | 서로 비슷한 기억을 공유하는 것 10명 / 편하게 감상을 남기는 것 1명 |
| 가장 유용할 기능 | 지역·연도별 동네 추억 4, 결과 링크 공유 3, 당시 유행 모아보기 2, 다른 사람 댓글 읽기 2 |
| 친구와 같이 열어 놓고 이야기할 것 같은지 (1~5점) | 5점 8명, 3점 1명, 2점 1명, 1점 1명 (평균 약 4.2) |

## 기획에 반영한 점
- 7/11명이 자료를 찾지 못해 그만둔 경험 → "자료가 흩어져 있다"는 가설을 일부 뒷받침
- 8/11명이 사진으로 확인하고 싶었다고 응답 → 추억 자료에 사진을 포함하기로 함
- 5개 MVP 기능이 모두 1명 이상에게 "가장 유용한 기능"으로 선택됨 → 기능 우선순위는 유지
- 응답자 다수가 인천 출신 → 인천 동 자료의 활용도가 높을 것으로 예상

## 한계

- 계획서상 8주차 전 완료 예정이었으나 실제 응답 수집은 10월 말~11월 초에 이루어짐 (학기 주차와의 정확한 대응은 사용자 확인 필요)
